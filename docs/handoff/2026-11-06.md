## Measured, and open

- **The planned assembler block has no consumer.** The night plan of 2026-11-05 named `umull`, `zip`
  and `tbl` as "forms the kernel will want". Measured 2026-11-06: no lowbit kernel (`l2/`, `l4/`,
  `l5/`, `l6/`) uses them (their mnemonics are `ldr mov fmov sdot and cmp add fmul ... addv fcvtas`,
  all encoded), lowbit is concluded, and no other program names them. Not built. The day a kernel
  needs a form, `tools/verify/neon_enc.cases` plus clang is the method (#187).
- **`link` already takes many files**, one declaration each (`pprog_ast` conses a `DLink` per
  declaration; `linked_asm` appends them in order). The plan's "link taking more than one file" is
  done by that reading; a comma form was not added.
- **Two comment strippers stay two.** `asm_strip_comment` (Mach-O: `;` and `//`) and
  `ea_strip_comment` (ELF: `//` and `@`) serve two assemblers with different comment grammars;
  merging them buys nothing the gates measure and risks the ELF bytes. Left as found.
- **PR #185 (the Pi witness pins the beacon's address)** is open since 2026-11-02, every check
  green, 27 commits behind master. It changes what runs on the Pi, so merging it is the owner's call.
- Carried from 10-29: a program importing the TLS stack needs `RAIL_ARENA_MB=1500` or more (the
  compiler does not yet say so at the default arena); t269 writes to /tmp; `tools/linux_libc.s`'s
  `snprintf` ignores `%.17g`; the seed format's transcription artefacts; the 64-frame record on the
  Pi. The x86 "three known defects" line is closed (`known_live.txt` empty since 10-29; #189 closed
  three more).
