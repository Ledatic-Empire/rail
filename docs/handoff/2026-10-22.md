## Open

- **What the gate does not cover** (new, by design): symbols are checked only in the tour (CONTRIBUTING names
  `addTwoNumbers` as a counterexample); paths are not checked in the repo `CLAUDE.md` (it names branches, tags and
  repositories in backticks); `README.md` is not checked at all (its release notes quote historical counts). A
  symbol cited in a `Defined here` line must be a compile.rail definition; a cited builtin resolves through the
  compiler's string literals, so a builtin renamed in `cg_bi` without its string changing would not be caught.
- **Autograd stayed through the step 5 cut** (new observation): the AUTOGRAD section (`grad_*`, the array and
  layer walkers, about 1,070 lines) is in the compiler and thirteen suite tests use `#grad`. The plan's step 5
  row named autograd; cutting it is a decision with a test-count change, not a deletion pass.

  on Linux; NUMERICS.md sentence 16 claims exactly that. A fix is a precision-honouring `%g` in the shim or a Rail
  printer that needs no libc.

  as `bl`; `.long` symbols are not rebased; an input with no data pointer rebases `__DATA+0`; every import's

  collects before it is full.
