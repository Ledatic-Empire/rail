## Decisions taken without asking (say so and they flip)

1. **`raise` is closed as "exit 1 at the end of `main`"**, not "fatal where it is raised". The
   next line still runs; t90's design (`error` is a value) stands. The gate case was rewritten to
   expect exit 1.
2. **`https_session_open` verifies the chain.** The old behaviour is
   `https_session_open_unverified`. No program in the tree or in rail-plasma calls it
   (grepped).
3. **The assembler refuses 7 forms the system assembler takes** (multi-lane `mov`, `mvn`,
   `ldrh` with a register index, the `uxtw`/`sxtw` index forms, `ldp` of w registers). They are
   named in `tools/test/asm_ranges/forms.txt`. The compiler emits none of them.
4. **`judge_test` still ignores an exit status under 128** when a test asserts on output (89
   tests end nonzero on purpose).
