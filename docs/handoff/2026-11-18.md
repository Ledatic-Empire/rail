Three decisions were taken without asking, each the smaller change. Say so and they flip:

1. **A definition named like a builtin is refused** (B5), not allowed to win. `cat parts = join "" parts`
   is let through because the estate carries it in dozens of programs.
2. **`str_sub` past the end returns the empty string** (C6), not an error.
3. **`curry` is an arity error, not 42** (C1). `(\a -> \b -> a * b) 6` then `7` needs partial
   application of let-bound lambdas, which the compiler does not have; it now says so at compile
   time where it used to crash.
